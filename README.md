# 拾刻校园通

一款面向高校学生的综合性校园服务微信小程序，提供校园生活所需的各类服务功能。

## 项目简介

拾刻校园通旨在为大学生提供便捷、高效的校园生活服务体验，整合了校园日常所需的各类功能模块，打造一站式校园服务平台。

## 功能模块

### 🏠 基础服务
| 模块 | 功能描述 |
|------|----------|
| 首页 | 校园服务入口聚合，快捷访问各类服务 |
| 课程表 | 个人课表查询与管理 |
| 消息中心 | 校园通知、系统消息推送 |
| 个人中心 | 用户信息管理与设置 |

### 📦 生活服务
| 模块 | 功能描述 |
|------|----------|
| 快递服务 | 快递代取、快递查询 |
| 跑腿服务 | 校园代买、代送服务 |
| 洗衣服务 | 洗衣预约与订单管理 |
| 打印服务 | 在线打印与订单管理 |
| 代取服务 | 图书馆代取、快递代取 |

### 🎓 学习服务
| 模块 | 功能描述 |
|------|----------|
| 成绩查询 | 个人成绩查询 |
| 考试安排 | 考试时间与地点查询 |
| 二手教材 | 教材买卖与交换 |

### 🎯 校园互动
| 模块 | 功能描述 |
|------|----------|
| 校园墙 | 校园动态、话题讨论 |
| 社团中心 | 社团信息与活动 |
| 失物招领 | 失物发布与认领 |
| 校园新闻 | 校园资讯与公告 |

### 🗺️ 其他服务
| 模块 | 功能描述 |
|------|----------|
| 校园导航 | 校内地图导航 |
| 健身中心 | 健身房预约与管理 |

## 技术栈

- **框架**: 微信小程序原生框架
- **UI组件库**: Vant Weapp (@vant/weapp ^1.11.7)
- **开发工具**: 微信开发者工具

## 快速开始

### 环境要求

- 微信开发者工具
- Node.js (推荐 LTS 版本)

### 安装步骤

1. **克隆项目**
   ```bash
   git clone https://github.com/cdgj/shike-campus-miniapp.git
   cd shike-campus-miniapp
   ```

2. **安装依赖**
   ```bash
   npm install
   ```

3. **打开项目**
   - 打开微信开发者工具
   - 选择"导入项目"
   - 选择项目根目录
   - 按下方「运行前必须完成的本地配置」填写自己的 AppID 与地图 Key

4. **预览与调试**
   - 在微信开发者工具中点击"预览"
   - 使用微信扫码预览

## 开发说明

### 页面配置

页面配置文件 `app.json` 中定义了所有页面路由和全局配置：

- `pages`: 页面路由列表
- `window`: 全局窗口样式
- `tabBar`: 底部导航栏配置
- `permission`: 权限声明

### 样式规范

- 使用 WXSS 编写样式
- 采用响应式设计，适配不同屏幕尺寸
- 主色调：`#367BFF` (蓝色)

### 数据存储

- 使用 `wx.setStorageSync` / `wx.getStorageSync` 进行本地数据存储
- 支持本地缓存用户信息和配置数据

## 运行前必须完成的本地配置

1. 在 `project.config.json` 中把 `appid` 改成你自己的小程序 AppID。仓库里保留的是项目作者的 AppID，它是公开标识而非密钥，但请不要用他人 AppID 上传代码。
2. 校园导航的地点搜索与路线规划全部由 `utils/map-service.js` 在本地用虚构数据生成，**不需要申请任何 API Key，也不会发起任何外部网络请求**。
3. 在微信开发者工具中执行「工具 → 构建 npm」，生成 `miniprogram_npm`。

## 演示数据与隐私说明

- 本项目**没有后端**，账号、订单、消息、成绩、聊天记录等均通过 `wx.setStorageSync` 保存在使用者设备本地，不会上传到任何服务器；本项目也不调用任何第三方 HTTP 接口。
- 代码中的姓名、学号、班级、社团、电话、邮箱、聊天内容全部是**虚构的演示数据**，不对应任何真实个人。
